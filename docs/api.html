How Xyra uses League of Legends

For Riot Games' product review (App ID 885964). Last updated: September 29, 2026.

Xyra is a free, open-source (MIT) League of Legends companion for Windows, with an optional Android app. It does not use the Riot Games API and ships no API key: it uses the League Client API and the Live Client Data API on the player's own PC. It has no ads, accounts or servers, and all data stays on the player's PC.

What it does

  • Champion select: shows OP.GG builds (runes, summoner spells, items, skill order) and imports them into the client when the player clicks Import, or automatically if the player turns that on. In ARAM it lists the bench options ordered by tier; a champion is only taken from the bench when the player clicks it. In Summoner's Rift it shows lane counters from public tier lists.
  • ARAM: Mayhem and Arena: reads the augment names the player already sees on screen with Windows text recognition, and labels each card with its static OP.GG tier for that champion in a separate click-through window; the top tier card is highlighted. No win rates of augments or Arena items are shown anywhere in the app, and the player always makes the pick.
  • The player's own data: match history, their own KDA, gold and level during the game (Live Client Data API), the LP each ranked game gave or took (the official LP, no MMR estimate), mastery and challenges.
  • Client actions, only on the player's click: create a lobby and invite friends, start or cancel the queue, put on a random or favorite owned skin in champion select (off by default), and loot: open what needs no key, forge keys, open chests with owned keys and disenchant shards of owned champions, asking for confirmation. It never touches skin shards, emotes or eternals.
  • Ready check: off by default. The player can turn on an automatic accept after a delay they choose, in the Game screen, where the app warns it is at their own risk; otherwise they accept in the client or with a tap on the phone notification. If this setting is not allowed under the current policy, we will remove it.
  • Official game settings (such as borderless window) changed from the app with the game closed.
  • Discord Rich Presence (off by default) and an Android app that pairs over the local network only, to follow champion select and accept the match with a tap.

What it does not do

No memory reading, injection or simulated keyboard or mouse input; no enemy cooldown, summoner spell or power spike tracking; no de-anonymization (no lobby reveal, no Riot ID history); no MMR estimates; no ads; no accounts or servers.

League Client endpoints

Reads, and the WebSocket events for them, unless noted.

  • /lol-summoner/v1/current-summoner, /lol-summoner/v2/summoners/puuid/{puuid}
  • /lol-gameflow/v1/session, /lol-gameflow/v1/gameflow-phase
  • /lol-champ-select/v1/session, /lol-champ-select/v1/pickable-champion-ids, /lol-champ-select/v1/skin-carousel-skins
  • /lol-champ-select/v1/session/my-selection (PATCH, the skin the player chose)
  • /lol-champ-select/v1/session/bench/swap/{championId} (POST, on click)
  • /lol-perks/v1/pages (creates or replaces only the page named "Xyra"), /lol-item-sets/v1/item-sets/{summonerId}/sets
  • /lol-matchmaking/v1/ready-check, /lol-matchmaking/v1/ready-check/accept, /lol-matchmaking/v1/ready-check/decline
  • /lol-lobby/v2/lobby, /lol-lobby/v2/lobby/invitations, /lol-lobby/v2/lobby/matchmaking/search, /lol-game-queues/v1/queues, /lol-chat/v1/friends
  • /lol-ranked/v1/current-ranked-stats, /lol-match-history/v1/products/lol/current-summoner/matches, /lol-end-of-game/v1/eog-stats-block
  • /lol-champions/v1/owned-champions-minimal, /lol-champions/v1/inventories/{summonerId}/champions/{championId}/skins
  • /lol-champion-mastery/v1/local-player/champion-mastery, /lol-challenges/v1/challenges/local-player, /lol-challenges/v1/summary-player-data/local-player
  • /lol-loot/v1/player-loot, /lol-loot/v1/recipes/initial-item/{lootId}, /lol-loot/v1/recipes/{recipe}/craft (POST, on click), /lol-rewards/v1/grants
  • /lol-game-settings/v1/game-settings, /lol-game-data/assets/…, /riotclient/region-locale

Live Client Data API

Port 2999, the player's own data only: /liveclientdata/activeplayer, /liveclientdata/playeritems, /liveclientdata/playerscores.

Data sources

OP.GG public statistics, CommunityDragon and Data Dragon assets, and the official patch notes.
